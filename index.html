Data token — lets the websites file quotes into this panel

Paste a fine-grained GitHub personal access token with Contents: read & write on the Harky39/on-the-spot-data repo. “Save & publish” stores it in this browser and publishes it to both websites, so new quote requests (with photos) appear under Quotes.

How to create the token (about 2 minutes)
  1. Sign in at github.com and open Settings → Developer settings → Fine-grained tokens.
  2. Click Generate new token and name it e.g. “on-the-spot-data”.
  3. Expiry: whatever you like (or no expiry).
  4. Repository access: choose “Only selected repositories” and tick Harky39/on-the-spot-data.
  5. Permissions: under Repository permissions, set Contents to Read and write. Leave everything else as No access.
  6. Click Generate token, copy it (starts with github_pat_) and paste it above. GitHub only shows it once.

Honest security notes

  • This login is a gate, not bank-grade security — the check happens in your browser. It keeps casual visitors out; it doesn't stop a determined one.
  • The data repo is public: anyone who knows a quote's exact URL could read it. Quote files use unguessable names, and email remains your private primary channel (every request also lands in peter.hark89@gmail.com).
  • If the token ever leaks, generate a new one on GitHub (the old one stops working immediately) and paste the replacement above.
